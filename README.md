# REPO Party for Windows

This repository only hosts the Windows installers of REPO Party, a mod pack launcher for R.E.P.O.

**Download the latest version:**
[REPO-Party-Setup.exe](https://github.com/vicxelcode/repo-party-releases/releases/latest/download/REPO-Party-Setup.exe)

The app updates itself after installing it. Every installer is signed, and the app verifies
the signature of each update before running it.

Not affiliated with semiwork or Thunderstore.
